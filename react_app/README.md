1. Use npm to create a new project
   
      npm create vite@latest my-react-app
   
2. Enter the project and install tools
   
       npm install axios
       npm install react-router-dom
   
3. start the npm project

       npm run dev


5. go to the login page,

       http://localhost:5173/login

 enter the username and password. If it's correct, it will redirect to 

       http://localhost:5173/my-new-page

Make sure the Spring Boot backend app is running.
